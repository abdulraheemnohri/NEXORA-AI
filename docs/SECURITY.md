# Security and Privacy

- Keep conversations, memories and documents in app-private storage.
- Do not send content to a remote service by default.
- Treat prompts, imported documents and model-generated tool calls as untrusted.
- Enforce allowlisted tool schemas and scoped permissions.
- Require confirmation for deletion, external transmission, package installation, shell execution and irreversible actions.
- Use Android Keystore for encryption key protection.
- Provide user-visible export and deletion controls.
- Never commit credentials, signing keys or API keys.
